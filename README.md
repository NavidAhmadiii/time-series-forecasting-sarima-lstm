# Time Series Forecasting with SARIMA & LSTM

## 📌 Project Overview
This project demonstrates end-to-end time series forecasting on daily female births dataset using:
- **Classical approach**: SARIMA (Seasonal ARIMA)
- **Deep learning approach**: LSTM (Long Short-Term Memory)
- **Feature Engineering**: Lag features, rolling statistics, temporal features

## 🛠 Tech Stack
- Python (Pandas, NumPy, Matplotlib)
- Statsmodels (SARIMA)
- TensorFlow/Keras (LSTM)
- Scikit-learn (Preprocessing, Evaluation)

## 📊 Results
| Model | RMSE | MAE |
|-------|------|-----|
| SARIMA | 6.66 | 5.44 |
| LSTM | 6.53 | 5.30 |

## 🚀 How to Run
1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Run: `python main.py`

## 📈 Key Skills Demonstrated
- Time Series Analysis & Preprocessing
- Feature Engineering for Temporal Data
- Model Training & Evaluation
- Comparing Classical & Deep Learning Approaches
- Reporting Results with Visualizations
